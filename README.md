## 📖 Descripción del proyecto

Este proyecto consiste en el desarrollo de un **portfolio académico personal** que reúne los trabajos, actividades y proyectos realizados durante el segundo curso del Ciclo Formativo de Grado Superior de Desarrollo de Aplicaciones Web (DAW).

La página principal funciona como punto de acceso a las diferentes asignaturas del curso, organizando los contenidos de forma visual, intuitiva y estructurada.

El objetivo es centralizar en un único espacio los proyectos desarrollados a lo largo del curso académico, facilitando su consulta y navegación.

## 📚 Asignaturas

El portfolio está organizado en torno a las ocho asignaturas que componen el segundo curso:

| Nº | Asignatura | Siglas |
|:--:|---|:--:|
| 01 | Desarrollo web en entorno servidor | DWES |
| 02 | Desarrollo web en entorno cliente | DWEC |
| 03 | Fundamentos de ciberseguridad | CIB |
| 04 | Diseño de interfaces web | DIW |
| 05 | Despliegue de aplicaciones web | DAW |
| 06 | Itinerario para la empleabilidad | IPE |
| 07 | Digitalización | DIG |
| 08 | Sostenibilidad | SASP |

Cada asignatura dispone de su propio espacio para organizar y presentar las actividades y proyectos correspondientes.

## 🛠️ Tecnologías utilizadas

Para el desarrollo de este proyecto se utilizan las siguientes tecnologías:

- **HTML5:** estructura y organización del contenido de la página.
- **CSS3:** diseño visual, estilos, distribución y presentación de los elementos.
- **PHP:** utilizado en los proyectos de las asignaturas que requieren programación del lado del servidor.
